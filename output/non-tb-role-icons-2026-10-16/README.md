# Approved non-Trouble Brewing icon replacements

October 16, 2026

This review set contains 63 replacements for the older icons outside the live Trouble Brewing + script. All 34 Trouble Brewing + roles are held back, as requested. The 60 icons approved in the previous round are also excluded.

The user approved these 63 candidates on October 16, 2026 and authorized their release. The exact approved SVGs replace 63 Game Master icons and the 35 corresponding reference-site icons. All 34 Trouble Brewing + icons and the 60 previously approved new icons remain unchanged.

## Review

Open review.html for a searchable, self-contained gallery. Every card pairs the existing artwork with its candidate. The artwork is shown at comparable ink size so the shapes can be judged. The original SVG files are preserved unchanged in originals/.

comparison-1.png through comparison-6.png provide the same comparisons in sheets. new-icons-preview.png shows all candidates, including a 32-pixel version of each.

The candidates were generated individually against the three approved examples, then traced to SVG, inspected at small size, and cleaned up. Each candidate uses a 512 by 512 viewBox, approximately 420 units of artwork on its longest side, one solid black compound path, transparent evenodd cutouts, and explicitly closed contours. There are no strokes, masks, text geometry, embedded rasters, or transforms in the candidate SVGs.

For relief printing, use a solid token base to support detached details. Standalone cutouts need connecting bridges. Set physical size in CAD or laser software and inspect the smallest features at that size before fabrication. Physical test pieces have not been produced.

## Sequence

1. Review and approve these non-Trouble Brewing candidates, with any requested revisions.
2. Apply and push the approved replacements to the relevant repositories.
3. Only after that release, create comparisons for the 34 Trouble Brewing + roles so a token-reprint decision can be made.

The held-back list and exact source-to-candidate filenames are recorded in manifest.json. The artwork snapshots record the state before this approved replacement. All SVGs outside the approved 63-role allowlist remain byte-for-byte unchanged.
