# Wolfsbane revised role icons, October 16, 2026

This set replaces all 60 icons from the first draft with the approved rounded, organic silhouette style. The three approved samples, Alchemist, Nightwatchman, and Lycanthrope, are included unchanged. The remaining 57 icons were generated individually against those samples and the original artwork, then traced to SVG.

## Contents

- svg/: the 60 revised icons. These same files are installed in the Game Master app's public/images directory.
- preview.png: the complete set, with large and 32-pixel views.
- revised-role-icons.zip: the 60 revised SVGs and this guide.
- all-role-icons.zip: all 157 catalog roles, using canonical role names as filenames. Existing artwork is included unchanged.
- manifest.json: catalog names, runtime artwork filenames, and preservation checks.

## Fabrication

The revised SVGs contain solid black geometry and transparent cutouts. Each uses a 512 by 512 viewBox and explicitly closed compound contours. There are no strokes, masks, raster images, fonts, or transforms in the new SVGs. The black artwork occupies approximately 420 units on its longest side.

For relief printing, place the artwork on a solid token base to hold detached details. Standalone cutouts need connecting bridges. Set physical size in CAD or laser software, preserve the evenodd hole rule, and inspect the smallest feature at the intended size before fabrication. Physical prints and engraving tests have not been performed.

Original artwork retains its original SVG structure. The clean-contour checks apply to the 60 revised files.

## Verification

All 167 pre-existing SVGs across the Game Master app and reference site were preserved byte-for-byte. The three approved samples were also preserved byte-for-byte. All 157 catalog roles have a corresponding artwork file, including legacy filename aliases. The generation and review process did not deploy the app or publish the reference site.
