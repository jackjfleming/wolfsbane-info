minion

Advocate

Each night, choose a living player (different from last night): if executed tomorrow, they do not die.

Storyteller procedure

Each night choose one living player, including Advocate themself, but not the player chosen the previous night. If that player is executed tomorrow while Advocate’s ability works, the execution occurs but the protected player does not die. A Zombuul that only registers as dead remains living for this choice. If Advocate is impaired during the effect, protection pauses.

Key interactions

The previous-night restriction still applies if no execution occurred.

Examples

Advocate protects themself; they are executed tomorrow but survive, so death-triggered abilities do not fire.
