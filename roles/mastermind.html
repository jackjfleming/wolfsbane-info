Mastermind

If the Alpha dies by execution and that would end the game, play one more day. Executing a good player then wins for Werewolves; otherwise Villagers win.

Storyteller procedure

If the actual Alpha dies by execution and that death would otherwise end the game, suspend that win and play through one more night and day. On the extra day, an executed good player gives Werewolves the win; an executed evil player or no execution gives Villagers the win. If the chosen player survives execution, apply the execution outcome based on that player’s team. Apply any active Bill inversion once to the final result.

Key interactions

Only an Alpha death by execution that would end the game triggers this extra day. A night death, an execution without Alpha death, or a successor handoff does not.

Examples

The Alpha dies by execution. The next day nobody is executed, so Villagers win.
