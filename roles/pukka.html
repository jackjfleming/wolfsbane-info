Pukka

Act on the first night. Each choice poisons the new target; the previous target dies while still poisoned, then the Pukka poison clears.

Storyteller procedure

Each night, including the first, wake Pukka to choose a player. If Pukka can act, poison the new target immediately. Then attempt to kill the previous Pukka-poisoned target while that target is still poisoned; clear only this Pukka poison afterward if the death was attempted, while leaving any other poison sources intact, including when protection prevents death. Keep the poison through any death-triggered ability resolution before clearing it. If Pukka is impaired, its existing effect pauses and may resume when Pukka regains ability; a choice made while impaired creates no new poison. If Pukka does not wake because another role suppresses its wake, an existing previous victim can still die if Pukka retains its ability.

Key interactions

Protection from death can prevent the delayed death without necessarily blocking the initial poison; Alpha-effect protection can block Pukka’s harmful effects according to its scope.

The prior victim is poisoned at death, so a death-triggered information ability can malfunction.

Examples

Pukka poisons Sage one night. Next night Pukka poisons another player, then Sage dies while poisoned; Sage’s death information may be false.
